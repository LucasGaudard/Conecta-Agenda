# Roadmap

## Etapa 1: Setup inicial

- Monorepo com `pnpm workspace`
- Apps `api` e `web`
- Packages `types`, `utils` e `ui`
- TypeScript, ESLint e Prettier
- Fastify com `GET /health`
- Next.js com paginas iniciais simples
- Prisma preparado

## Etapa 2: Modelagem inicial

- Definir entidades principais
- Criar schema Prisma
- Configurar migrations
- Preparar conexão real com PostgreSQL

## Etapa 3: Autenticacao

- Registro e login
- Hash de senha com bcrypt
- JWT no backend
- Fluxos básicos no frontend

## Etapa 4: Agenda

- Cadastro de disponibilidade
- Serviços
- Horários
- Página pública de agendamento

## Etapa 5: Operacao SaaS

- Organização por conta
- Convites e papéis
- Configurações de negócio
- Preparação para cobrança
